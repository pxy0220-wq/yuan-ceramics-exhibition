# 草原与窑火 · 元代陶瓷线上展厅

《元代陶瓷中的蒙古生活习俗反映》课堂汇报配套的离线展览。六件器物，三个动作：握、围坐、俯看。

## 一、怎么打开

1. 先把整个 `元代陶瓷_线上展厅` 文件夹拷到教室电脑，**不要只拷 `index.html`**。
2. 双击 `index.html`，建议用 Chrome 或 Edge 打开。
3. 点击「进入展览」，再点「全屏」。
4. 不需要联网。图片、视频、环境音、3D 纹理都在文件夹内。

如果电脑没有启用 3D，页面会自动进入 2D 目录，内容仍然完整；也可以在任何时候点右上角「2D 展板模式」。

## 二、课堂上的两种用法

- **30–60 秒插入**：进入展览后，用「下一站」依次看 01–06，每件停留几秒，最后到尾厅。也可以直接点底部路线圆点跳转。
- **课后完整参观**：约 8–10 分钟。每件器物可点旁边的资料夹，打开 2D 档案看图片、视频、看点、年代与尺寸、表述边界。
- **手机/二维码**：手机端自动使用 2D 档案，不加载 3D；适合课后扫码继续看。二维码需要先把整个文件夹上传到可公开访问的地址（如 GitHub Pages），离线教室内不适用。

## 三、操作

| 操作 | 说明 |
| --- | --- |
| 拖动空白处 | 环顾展厅 |
| 点击文物 / 资料夹 | 打开该器物的 2D 档案 |
| 下一站 / 上一站 | 沿参观路线前进或后退 |
| 底部路线圆点 | 跳到序厅、任一器物或尾厅 |
| 右上角「2D 展板模式」 | 进入目录；手机上会自动进入 |
| 右上角「声音：关」 | 环境音默认关闭，点击后才播放 |
| 右上角「全屏」 | 进入/退出全屏 |
| Esc | 关闭档案、目录、素材授权；在 3D 中回到序厅 |
| 左右方向键 | 在 3D 中切换上一站/下一站 |

档案内：

- 图片标签可切换不同角度/示意图。
- 01、02、03、05 有图片热点，点小圆点看局部说明。
- 04 的「俯视旋转」标签下，可拖动转杯或使用键盘左右键，观察杯身转动、高足不动。
- 06 的「描金」互动可分步查看金线位置；金线是按残存痕迹复原的示意。
- 每个档案底部都有「表述边界」，说明哪些是文献可证的、哪些是推断或民间传说。

## 四、展览结构

- **序厅**：器物的形状，先于纹饰。
- **第一展厅 · 饮与携**：01 元青花龙纹高足杯；02 元青花凤首扁壶。
- **第二展厅 · 食与礼**：03 元代青花折沿大盘；04 高安窑高足转杯。
- **第三展厅 · 储与色**：05 元磁州窑白地黑花龙凤纹罐；06 蓝釉描金匜。
- **尾厅**：器物是生活的注脚。

## 六、设备与离线说明

- 建议 Chrome / Edge 90 以上，桌面分辨率 1280×720 以上。
- 3D 需要 WebGL；不支持时自动降级为 2D，不会白屏。
- 所有 3D 纹理、资料夹内页小图均为内嵌 data URI；2D 图片、视频、音频使用相对路径。整个文件夹拷走后，`file://` 直接打开也能用。
- 手机端（宽度 ≤ 820px）只显示 2D 目录与档案，避免移动端 WebGL 发热与卡顿。
- 环境音是合成音效，不是文物原声或现场录音；默认关闭。

## 七、素材与表述

- 3D 模型是按器形比例搭建的**简化示意**，不是文物扫描、测绘或复原。
- 部分图片为同类器参考，档案图注与「表述边界」中已注明，不能当作本件器物的照片使用。
- 器物年代、尺寸、馆藏以公开资料为准；有争议处保留「据传」「推测」等限定语。
- 图片、视频、音频与字体授权见 `版权与来源.csv` 和页面内「素材授权」。字体使用系统字体，不内嵌商业字体。

## 八、PPT 里怎么放

- 在现有某页的图片或文字上插入超链接，指向 `元代陶瓷_线上展厅/index.html`（相对路径）。PPT 与文件夹放在同一目录层级时最稳。
- 最后一页可放二维码，指向公开网址；离线教室建议同时保留文件夹超链接，二维码只作为课后入口。
- 不要修改 PPT 既有排版；以上两项都只是加链接/加二维码。

## 九、常见问题

**打开后是 2D 目录，没有 3D？**  
电脑或浏览器未启用 WebGL，或当前是手机宽度。2D 内容完整，不影响讲解。

**资料夹里的图片是空白？**  
请确认整个文件夹完整拷贝，尤其是 `js/textures.js` 与 `assets/img/`。

**没有声音？**  
默认关闭。点右上角「声音：关」切换；若浏览器拦截，再点一次即可。

**视频不动？**  
视频是静音短片，需要点播放键；首次播放需要一次真实鼠标点击。

**能不能直接发 index.html 给别人？**  
不能。必须连同 `assets/`、`js/`、`css/` 整个文件夹一起发送或打包。
